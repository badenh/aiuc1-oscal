# AIUC-1 OSCAL catalog (unofficial)

This repo holds an OSCAL 1.1.3 catalog of the AIUC-1 AI agent standard, generated by the companion `aiuc1-oscal` converter. One directory holds each quarterly edition.

Each edition directory also contains:

* `PROVENANCE.md`: retrieval time and SHA-256 hash of every source page
* `reconciliation.md`: check results and source observations
* `SHA256SUMS`: the catalog hash

## Structure at a glance

```
group  a  "Data & Privacy"                      (domains A–F)
└─ control  a001  class=requirement             A001 Establish input data policy
   ├─ props: application, frequency, requirement-type, capability*, keyword*, crosswalk*
   ├─ part  statement                           requirement text
   └─ control  a001.1  class=evidence-control   A001.1 Policy for input data ownership…
      ├─ props: control-tier (core|supplemental), evidence-kind, evidence-category,
      │         typical-location*, capability*
      ├─ part statement / item a., b., …        control activities
      └─ part assessment-method / assessment-objects   typical evidence
```

Withdrawn requirements (E007, E014) carry `status=withdrawn` and `incorporated-into` links (E004, E017).

AIUC-specific props use the namespace `https://aiuc1-oscal.invalid/ns/oscal`, which is a placeholder pending a chosen domain. See the converter README for the full mapping, and for which choices are inference rather than AIUC definitions.

## Profile usage (example)

Select only the core controls, or only the mandatory requirements, by `prop` in an OSCAL profile or downstream tooling. For example, filter `props[name=control-tier][value=core]`. OSCAL profiles can't select on props natively (only `with-ids` or `matching` patterns), so resolve the ID list first.
